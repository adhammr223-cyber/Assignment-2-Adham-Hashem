# Student Registration Form

A registration form with text, email, phone, date, selection and file inputs.

## Technologies

HTML.

## Run locally

1. Download or clone the repository.
2. Open `indax.html` in a browser.
3. Keep the existing image and stylesheet folders in place.

## Project scope

The form is a front-end exercise and does not create accounts or store submissions.
