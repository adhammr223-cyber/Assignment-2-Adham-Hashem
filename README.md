# نموذج تسجيل طالب

## التقنيات

HTML.

## فكرة المشروع

تطبيق حقول النماذج: نص، بريد، هاتف، تاريخ، خيارات، مهارات وملف صورة.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `indax.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `indax.html`

## حدود المشروع

النموذج واجهة تدريبية فقط. لا توجد خدمة لإنشاء حساب أو حفظ البيانات؛ لا تدخل كلمة مرور حقيقية.
