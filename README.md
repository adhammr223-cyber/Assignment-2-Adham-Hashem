# نموذج تسجيل طالب

مشروع تعليمي لأدهم مؤيد هاشم، مبني على الكود الحالي بدون إضافة مكتبات أو إطار عمل.

## التقنيات

HTML.

## ما الذي يقدّمه؟

تطبيق حقول النماذج: نص، بريد، هاتف، تاريخ، خيارات، مهارات وملف صورة.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `indax.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `indax.html`

## حدود المشروع

النموذج واجهة تدريبية فقط. لا توجد خدمة لإنشاء حساب أو حفظ البيانات؛ لا تدخل كلمة مرور حقيقية.

## مراجعة سريعة

جرّب الصفحة على شاشة هاتف، وتنقّل بلوحة المفاتيح، وتحقق من ظهور الصور وعمل الروابط. لا يحتاج المشروع تثبيت حزم.
